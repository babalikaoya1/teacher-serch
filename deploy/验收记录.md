## 修复过的验收失败

- 队列领取时，SQLite 返回的无时区日期与带时区日期比较出错：改由数据库执行条件更新，重跑通过。
- 带时区消息写入 SQLite 前没有统一 UTC：增加统一转换和北京时间回归，确保三天有效期准确。
- 首次打包无法访问 Python 的 Tcl 资源，出现 `tkinter installation is broken`。确认是沙箱访问限制后，在允许读取资源的环境重建；最终 exe 自检通过。收集第三方测试模块产生的无效隐藏导入，也已由独立打包脚本过滤。
- HTTP 联调业务断言通过后，临时日志清理出现 `PermissionError: [WinError 32]`；强制终止进程树又受沙箱权限限制。最终改为专属停止文件触发服务正常关闭，同一联调命令返回 0。
- 助手下载路径留空时未回退默认路径：已修正；订单卡片同时显示原消息发布时间和导入日期。
